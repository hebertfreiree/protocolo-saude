YouTube — opções de fonte (em ordem de precisão)

1. Studio via cookies do Chrome (recomendado): número idêntico ao do Studio em tempo real. Sem setup. Botão "Conectar Studio (Chrome)" no slot.
2. OAuth (YouTube Analytics API): também exato, mas precisa criar credenciais no Google Cloud (campos abaixo).
3. Mixerno (padrão, sem login): ~1.000 de imprecisão pelo arredondamento da API pública.
Como obter as credenciais?
  1. Vá em console.cloud.google.com → crie ou selecione um projeto.
  2. "APIs & Services" → "Library" → ative YouTube Data API v3 e YouTube Analytics API.
  3. "APIs & Services" → "OAuth consent screen" → External → preencha o básico → adicione seu Gmail em "Test users".
  4. "APIs & Services" → "Credentials" → "Create Credentials" → "OAuth client ID" → tipo Desktop app.
  5. Copie o Client ID (e o Secret se aparecer) e cole acima.
  6. Volte aqui, clique em "Conectar Google" no slot do YouTube.

Como preencher

  • YouTube: cole o link do canal ou apenas o ID que começa com UC... (ex: UCxtDy586BIg_d9NyFntEwmg). Os inscritos são lidos via mixerno.space (mesma API dos contadores ao vivo do livecounts.io). Sem login.
  • Instagram: digite @usuario ou cole o link do perfil. O perfil precisa ser público; o app lê a tag de descrição da página pública.
  • TikTok: digite @usuario ou cole o link. Perfil precisa ser público.
  • Se uma rede não for usar, deixe em branco — só será somado o que estiver preenchido.
  • Use o botão Testar de cada slot para conferir antes de iniciar.
