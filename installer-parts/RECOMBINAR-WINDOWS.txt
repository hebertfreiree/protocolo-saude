=== v3.8 — Coletor via Tampermonkey (caminho REAL) ===

NOVA ESTRATEGIA: o app sobe um servidor HTTP local na porta 7777.
Voce instala um script Tampermonkey no seu Chrome. Quando voce
abre o YouTube Studio Analytics na pagina de inscritos, o script
le o numero direto do DOM (no contexto real da sua sessao logada)
e manda pro servidor local. Resultado: numero EXATO.

INSTALACAO:
1. APAGUE tudo antigo:
   - Pasta antiga "Seguidores Tempo Real"
   - %APPDATA%\seguidores-tempo-real (factory reset)
     cmd: rmdir /s /q "%APPDATA%\seguidores-tempo-real"
   - Os zip parts antigos

2. Baixa os 7 arquivos com Ctrl+F5.

3. cmd na pasta:
   copy /b SeguidoresTempoReal.zip.part00 + SeguidoresTempoReal.zip.part01 + SeguidoresTempoReal.zip.part02 + SeguidoresTempoReal.zip.part03 + SeguidoresTempoReal.zip.part04 + SeguidoresTempoReal.zip.part05 + SeguidoresTempoReal.zip.part06 SeguidoresTempoReal.zip

4. Extrai e roda.

5. Configura o slot YT com o Channel ID. Salva.

6. Na tela de setup, vai aparecer um card VERDE no topo
   "Coletor Tempo Real via Tampermonkey":
   a. Clica "Abrir Tampermonkey no Chrome" -> instala a extensao.
   b. Volta no app, clica "Instalar script no Tampermonkey".
      O Chrome abre uma pagina do Tampermonkey perguntando se
      voce quer instalar. Clica em "Install".
   c. Clica "Abrir Studio Analytics". A pagina abre no Chrome
      com banner discreto no canto "Coletor ativo".
   d. Deixa essa aba aberta em segundo plano.
   e. O status no app vai virar verde com "✓ recebendo dados...".

7. Inicia a contagem em tela cheia. O numero agora bate com Studio.
