=== v3.9 — 3 jeitos de coletar do Studio ===

Como o Studio so mostra o numero exato pra quem esta logado (voce),
voce precisa rodar um pedacinho de codigo no SEU Chrome.
Agora tem 3 opcoes (escolha a que se sentir mais a vontade):

A) F12 SNIPPET (zero install, recomendado pra paranoicos)
   - Abre Studio Analytics no seu Chrome (ja logado)
   - F12 -> Console
   - Cola 1 codigo (visivel inteiro antes de colar) -> Enter
   - Roda a cada 5s enquanto a aba estiver aberta
   - Pra parar: fecha a aba

B) BOOKMARKLET (1 favorito, sem extensao)
   - Arrasta um link pra barra de favoritos do Chrome
   - Na pagina do Studio, clica no favorito -> manda 1 coleta
   - Clica de novo pra atualizar

C) TAMPERMONKEY (auto, requer extensao 1x)
   - Instala Tampermonkey (Chrome Web Store)
   - Instala o script (link gerado pelo app)
   - Atualiza automatico sempre que Studio estiver aberto

Todos os 3 fazem a MESMA coisa por baixo:
le o numero da pagina do Studio (no contexto do SEU navegador
logado) e manda pro app via servidor local em 127.0.0.1:7777.

INSTALACAO:
1. APAGUE pasta antiga + parts antigos + %APPDATA%\seguidores-tempo-real
2. Baixa os 7 arquivos com Ctrl+F5

4. Extrai e roda
