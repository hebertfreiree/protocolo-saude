=== Como recombinar o app no Windows (Nitro 5) ===

1. Baixe os 6 arquivos da pasta para a mesma pasta no Windows (ex: Downloads):
   - SeguidoresTempoReal.zip.part00
   - SeguidoresTempoReal.zip.part01
   - SeguidoresTempoReal.zip.part02
   - SeguidoresTempoReal.zip.part03
   - SeguidoresTempoReal.zip.part04
   - SeguidoresTempoReal.zip.part05

2. Abra o Prompt de Comando NESSA pasta:
   - Modo facil: na barra de endereco do Explorer, digite "cmd" e tecle Enter.

3. Cole o comando (selecione a linha toda e Enter):

   copy /b SeguidoresTempoReal.zip.part00 + SeguidoresTempoReal.zip.part01 + SeguidoresTempoReal.zip.part02 + SeguidoresTempoReal.zip.part03 + SeguidoresTempoReal.zip.part04 + SeguidoresTempoReal.zip.part05 SeguidoresTempoReal.zip

4. Vai aparecer um SeguidoresTempoReal.zip de 108 MB.
   Clique direito -> "Extrair tudo".

5. Entre na pasta extraida "Seguidores Tempo Real" e execute:
   "Seguidores Tempo Real.exe"

   (Como nao esta assinado, o Windows SmartScreen pode pedir confirmacao:
    clique em "Mais informacoes" -> "Executar assim mesmo")
